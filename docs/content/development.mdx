---
title: "本地开发"
---

从仓库根目录安装 Node.js 24，然后运行：

```sh
npm ci
npm run dev
```

根依赖安装后会按锁文件安装前端、管理后台和文档的依赖。开发启动脚本构建前端 Worker，将管理后台和文档静态资源合并到同一资产目录，初始化本地 D1 并启动 Wrangler。首次启动会生成本地 `.dev.vars`。修改页面或服务端代码后，重新启动以测试最新的生产构建。

## 验证更改

```sh
npm run test:content-markup
npm run test:worker
npm run build
npm --prefix docs test
npx playwright install chromium
npm run test:e2e
```

Playwright 使用专用临时 D1、R2 与会话密钥，从同一站点访问 `/`、`/admin/` 与 `/api/`。浏览器报告保存在 `playwright-report/` 中。
