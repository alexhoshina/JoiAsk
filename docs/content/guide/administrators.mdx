---
title: "管理员与密码恢复"
---

新安装没有默认管理员或默认密码。运维 CLI 使用 Wrangler 凭据直接访问指定 D1。本地开发使用 `--local`，已部署的站点使用 `--remote`。生产操作前检查当前 Cloudflare 账号和资源名称。

以下是 PowerShell 7 中创建、重置与提升权限的命令。创建与重置会从管道读取掩码输入的密码。

```powershell
Read-Host -MaskInput '初始密码' | node scripts/admin.mjs --remote create site-admin
Read-Host -MaskInput '新密码' | node scripts/admin.mjs --remote reset-password site-admin
node scripts/admin.mjs --remote promote site-admin
```

Bash 用户可以参考[快速开始](./quick-start.mdx)中的掩码输入示例，将目标改为 `--remote`。如果部署指定了 Worker 名称，在远端管理命令中使用相同的 `--name <Worker 名称>`。如果使用自定义 Wrangler 配置，请给命令添加 `--config <路径>`，并确认其中的 `DB` 绑定与实际运行的 Worker 一致。重置密码会撤销已有管理员会话。

超级管理员在管理后台管理管理员账号。普通会员可在前台使用绑定的邮箱重置密码。流程见[投稿与邮箱](./usage.mdx)。
