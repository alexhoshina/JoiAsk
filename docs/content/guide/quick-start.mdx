---
title: "快速开始"
---

**新安装没有默认管理员或默认密码。** 首次体验可以使用本地的 Cloudflare 运行时。

## 1. 安装并启动

在仓库根目录执行：

```sh
npm ci
npm run dev
```

首次启动会构建用户站、管理后台与文档，生成本地密钥，初始化 D1 后启动 Wrangler。浏览器打开终端显示的地址。

## 2. 创建本地管理员

使用新建的本地 D1 时，也可以在仓库根目录的 `.dev.vars` 中加入 `JOIASK_INITIAL_ADMIN_USERNAME` 和 `JOIASK_INITIAL_ADMIN_PASSWORD`，保留文件中原有的两个运行密钥。重启 `npm run dev` 后，用这组凭据登录 `/admin/`。登录成功即可从本地文件中移除两个管理员变量。

使用管理员 CLI 时，保持本地服务运行，在另一个终端输入命令。

在 PowerShell 7 中输入：

```powershell
Read-Host -MaskInput '管理员密码' | node scripts/admin.mjs --local create site-admin
```

在 Bash 中输入：

```bash
read -rs -p "管理员密码：" password
printf '%s\n' "$password" | node scripts/admin.mjs --local create site-admin
unset password
```

访问 `/admin/` 登录。前台位于 `/`，文档位于 `/docs/`。

## 3. 发布站点

新站发布后，在 Cloudflare 控制台的目标 Worker 下打开 **Settings → Variables and Secrets**。用户名 `JOIASK_INITIAL_ADMIN_USERNAME` 选 **Text**，也可选 **Secret** 隐藏控制台中的值。密码 `JOIASK_INITIAL_ADMIN_PASSWORD` 选 **Secret**。点击 **Deploy** 后，用这组凭据登录站点的 `/admin/`。首次部署时也支持通过部署 CLI 的同名环境变量创建管理员。[首次部署示例](./deployment.mdx#首次部署与管理员)
