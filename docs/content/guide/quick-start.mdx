---
title: "快速开始"
---

**新安装没有默认管理员或默认密码。** 首次体验可以使用本地的 Cloudflare 运行时。

## 1. 安装并启动

在仓库根目录执行：

```sh
npm ci
npm run dev
```

首次启动会构建用户站、管理后台与文档，生成本地密钥，初始化 D1 后启动 Wrangler。浏览器打开终端显示的地址。

## 2. 创建管理员

保持本地服务运行，在另一个终端执行：

在 PowerShell 7 中输入：

```powershell
Read-Host -MaskInput '管理员密码' | node scripts/admin.mjs --local create site-admin
```

在 Bash 中输入：

```bash
read -rs -p "管理员密码：" password
printf '%s\n' "$password" | node scripts/admin.mjs --local create site-admin
unset password
```

访问 `/admin/` 登录。前台位于 `/`，文档位于 `/docs/`。

## 3. 发布站点

按[部署与更新](./deployment.mdx)连接 Cloudflare 账号并创建远端资源。生产管理员使用相同命令的 `--remote` 参数在远端 D1 中创建。
