---
title: "快速开始"
---

**新安装没有默认管理员或默认密码。** 首次体验可以使用本地的 Cloudflare 运行时。

## 1. 安装并启动

在仓库根目录执行：

```sh
npm ci
npm run dev
```

首次启动会构建用户站、管理后台与文档，生成本地密钥，初始化 D1 后启动 Wrangler。浏览器打开终端显示的地址。

## 2. 创建本地管理员

保持本地服务运行，在另一个终端执行：

在 PowerShell 7 中输入：

```powershell
Read-Host -MaskInput '管理员密码' | node scripts/admin.mjs --local create site-admin
```

在 Bash 中输入：

```bash
read -rs -p "管理员密码：" password
printf '%s\n' "$password" | node scripts/admin.mjs --local create site-admin
unset password
```

访问 `/admin/` 登录。前台位于 `/`，文档位于 `/docs/`。

## 3. 发布站点

发布到一个全新的 D1 时，可在 `npm run deploy` 的环境中设置 `JOIASK_INITIAL_ADMIN_USERNAME` 和 `JOIASK_INITIAL_ADMIN_PASSWORD`，由部署命令一次性创建首个超级管理员。也可在部署后用上面的 CLI 命令，将 `--local` 换成 `--remote`。[首次部署示例](./deployment.mdx#首次部署与管理员)
