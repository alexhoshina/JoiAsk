站点的 `wrangler.jsonc` 定义 Cloudflare 绑定。D1 的 `DB` 保存账号、问题、话题与设置。R2 的 `FILES` 存放头像、图片和表情。Durable Object `REALTIME` 向 WebSocket 与 SSE 客户端广播更新。消息队列 `MODERATION` 处理异步审核。

## 站点密钥

为 `SESSION_SECRET` 和 `SETTINGS_KEY` 分别生成独立随机值，通过 Wrangler Secrets 保存。会话密钥用于登录状态，设置密钥保护 SMTP 密码和审核服务 API 密钥。首次本地运行会在被 Git 忽略的 `.dev.vars` 中创建本地密钥。备份生产密钥；更换设置密钥后，已有的加密配置需要重新录入。

## 内容审核

后台「设置」可以填写兼容 Chat Completions 的 HTTPS 服务基础地址、模型名称、API 密钥及垃圾投稿判定标准。保留现有密钥时留空即可；更换服务地址时需要重新提供密钥或清除已保存的密钥。设置只有管理员能够更新。

## 用户注册与邮件

用户通过自己的 B 站 UID 和个性签名完成验证。后台可以启用「投稿需要已验证用户」。邮箱绑定和密码找回需要在后台启用并配置 SMTP，详见[投稿与邮箱](./usage.mdx)。
